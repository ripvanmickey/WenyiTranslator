文译 1.16.7（构建 1269），适用于 Apple Silicon Mac，macOS 14 或更高版本。

## 修复内容

- 修复 Cloudflare 配置或文字发送授权缺失时，恢复按钮错误显示「选择 Nari 正式版模型」的问题。
- 对应按钮现在显示「配置 Cloudflare」，直接打开 API 密钥中的 Cloudflare 配置。
- 通用设置错误的恢复按钮统一显示「打开设置」，不再使用已暂停服务的专用文案。
- Cloudflare 文字发送授权继续由用户明确选择，不会自动开启。

## 安装与使用

下载 `Wenyi-1.16.7-1269-macOS14-arm64.dmg`，退出旧版，将「文译」拖入「应用程序」替换旧版。

遇到文字发送授权提示时，进入「设置 → API 密钥 → Cloudflare」，勾选「允许将字幕文字发送到 Cloudflare」，再保存配置。
