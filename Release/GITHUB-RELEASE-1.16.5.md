文译 1.16.5（构建 1267），适用于 Apple Silicon Mac，macOS 14 或更高版本。

## 本次更新

- 媒体模式整合到主窗口右侧配置栏，左侧复用字幕显示区；优化窗口最小宽度、选择框对齐和中英文／日文布局。
- 媒体字幕支持本机 Nemotron 和 Gemini 音轨识别，继续支持 OpenAI、YouTube 已有字幕及 SRT／VTT 导入。复用本地缓存，可从已有检查点继续准备字幕，已就绪部分可先播放。
- 改善 Chrome／Safari 视频关联与同步，退出全屏或短暂读取失败后重试；媒体模式的播放／暂停按钮控制关联视频，停顿时保留首页字幕。
- 统一悬浮字幕为白色原文、黄色译文及半透明黑色背景；支持拖动跨屏，大小、行高等配置收进高级选项。
- 修复 Gemini Live 字幕持续累积不分段的问题，按完整句子及回合结束收尾；中断时保留已收到的内容。
- 暂停 Azure／MAI、Nari、Jev，移除其设置与密钥配置入口。旧模式不再自动启用，已有密钥保留。
- 录制或媒体同步期间锁定模式与相关配置，避免切换导致字幕中断。

## 安装

下载 `Wenyi-1.16.5-1267-macOS14-arm64.dmg`，打开后将「文译」拖入「应用程序」。升级前请退出旧版。校验文件与安装包一同提供。

## 使用与验证说明

- 本地构建及 48 项回归测试通过；安装包签名、macOS 14 原生依赖兼容性和磁盘映像完整性另行检查。
- 云端服务需要用户自己的 API 密钥、模型权限及可用额度。开发测试未使用用户密钥上传音频，真实云端识别质量与延迟仍需按实际账号确认。
- 浏览器同步需授予文译自动化权限，并在所选浏览器中开启「允许来自 Apple 事件的 JavaScript」。设置步骤与演示见媒体栏的浏览器同步部分。
- 本包为临时签名，未经过 Apple 公证或 Mac App Store 审核；系统可能提示无法验证开发者。
- 不包含识别模型、用户密钥、录音或转写记录。首次使用本地识别可能需要下载模型；云端音轨识别和翻译会产生所选服务的 API 用量。
