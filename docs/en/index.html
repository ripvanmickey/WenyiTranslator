From listening to reviewing

YouTube caption preloading

Prepare full caption blocks while watching in Chrome or Safari. Captions follow video time, local caches load automatically, and unfinished translations can resume. Optional OpenAI audio transcription uploads audio and incurs API usage.

Floating bilingual captions

Show the original text, the translation, or both. Keep the captions near the video as you watch.

On-device speech recognition

Download Nemotron or Qwen3-ASR in the app. Translate through LM Studio on the same Mac, or use Index online translation, which receives only the text to translate.

Save and manage transcripts

Save original text and translations as text files, then copy their contents, rename them, or open the saved files.

Get started on Mac

Wenyi 1.16.9 (build 1273) requires Apple Silicon (M1 or later) and macOS 14.0 or later, including macOS 27. The interface is available in English, Simplified Chinese, and Japanese.

Read the full installation guide ↗

  1. Install Wenyi. Open the downloaded DMG and drag Wenyi into Applications.
  2. Choose an audio input. Select Mac Audio, Microphone, or Media to connect YouTube, and grant permission when prompted. Audio-only system capture requires macOS 14.2 or later.
  3. Set up recognition and translation. Download a speech model in local mode, then configure LM Studio or choose Index online translation.
  4. Start listening. Select the source and target languages and choose what to show in the captions.
