# 配置界面更新 · build 1164

安装包：AirTranslate-1.16.0-Local-Qwen-layout-arm64.app.zip。停止并退出旧版，解压后用同名 AirTranslate Local Qwen.app 替换应用程序中的旧版。应用标识保持不变，已保存配置继续沿用。应用是本地 ad-hoc 签名，未经过 Apple 公证。

## 新配置路径

General → Processing Mode 选择 Apple → Apple 模式 · 翻译引擎选择「本地模型翻译」。选择后打开配置弹窗；已有配置可点击摘要旁的「配置…」。

弹窗提供服务地址、模型列表及模型 ID、本地服务密钥字段，以及读取模型列表、保存密钥、删除密钥操作。「保存配置」会提交地址、模型与密钥变更、启用本地翻译，并返回 General。「取消」放弃本次更改，密钥操作也不会提前写入钥匙串。密钥原值不回显。

General 只显示已配置模型、服务地址、密钥状态和配置入口，以及「测试翻译」「测试长句翻译」按钮；不再展示编辑字段。选择本地翻译后，隐藏不适用的 Apple 翻译质量设置与 Jev 选项。

两个测试都按主窗口当前选择的源语言和目标语言运行。测试文本支持当前应用内提供的英语、韩语、日语、简体中文、西班牙语、法语和德语，不再固定为日中翻译。
