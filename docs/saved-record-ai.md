# 已保存记录的 AI 处理

适用版本：文译 1.16.10，测试构建 1277。Apple Silicon，macOS 14 及以上。

停止当前录制或媒体同步后，打开「已保存记录」，选中记录。将鼠标停留在任一 AI 按钮上，可查看当前模型及文字发送说明；编辑区保留原来的紧凑排版。加载指示不会改变按钮或标题输入框宽度，长提示在编辑区内滚动显示。

- 非媒体模式：使用当前实际启用的文字翻译模型，包括 Index 在线翻译、Cloudflare Workers AI 或已配置的本地模型。OpenAI GPT-4.1 mini 文字翻译使用同一模型。
- 媒体模式：使用媒体配置栏的「翻译模型」，与音轨识别来源无关。例如，Nemotron 识别配合 Cloudflare 翻译时，记录处理使用选中的 Cloudflare 模型。
- 「AI 整理正文」补充标点和段落，保留原语言、完整内容及原文/译文配对。
- 「AI 生成标题」对记录内容生成简短标题；长记录使用有界的开头、中间及结尾节选。
- 结果先更新草稿，点击「保存修改」才写入 TXT 文件并更新文件名。记录页继续不提供原文、译文编辑框，可使用复制或「在访达中显示」查看正文。

不会为了处理记录而自动选择其他提供方、其他收费模型或旧的本地模型。实时音频专用模型、纯语音识别模型及 Apple 翻译不作为通用文本写作模型使用；当前选择不支持时，在记录页显示具体原因。

选择云端模型后，点击对应 AI 按钮会将记录文字发送给所选提供方，并产生对应 API 用量。密钥使用该提供方的现有配置。Cloudflare 继续要求已保存 Account ID、API Token 和模型，并开启文字发送许可。本地模型的地址仍仅接受回环地址。请求失败、返回不完整或正文变化过大时保留原草稿，不切换服务重试；关闭记录页或切换所选 AI 时取消未完成操作。

构建时沿用 `--build-system native`，最低系统版本 14.0 与当前 Xcode SDK 版本分别保留。`script/audit_macos14_bundle.py` 在检查原生依赖之外，也会拒绝主程序错误地记录旧版 SDK 的安装包。

## 验证范围

通过模拟网络响应验证：当前模型与请求目标匹配、不同服务密钥不混用、媒体翻译模型优先、有界标题节选、正文分块、完成状态和输出上限检查、缺少许可或配置时不发送请求，以及错误时草稿保护。未使用用户密钥或用户记录进行真实云端请求，因此各服务当时的可用性、额度及生成质量仍以实际账户使用为准。

源码构建见项目 Package.swift。本次验证使用 macOS 27 测试机；历史测试目标包含 macOS 26 及以上的 Speech API，因此测试时指定对应的运行目标，分发应用仍单独以 macOS 14 为最低版本构建：

```sh
swift test --triple arm64-apple-macosx27.0 --filter 'TranscriptAIServiceTests|CloudflareTranslationTests|LocalTranslationServiceTests|TranscriptPersistenceTests'
```
