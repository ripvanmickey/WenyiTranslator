# 增量字幕更新与测试说明（build 1166）

本版保留 Apple Speech + 本地 LM Studio 架构，支持现有 35B/27B 模型配置。未替换语音识别或引入新的云端服务。

## 改动

- 同一条识别结果持续增长时，复用未变化的前句，只翻译新增或变化的尾部。识别修正会使变化处之后的缓存失效。
- 未完成片段参考少量前后文；后文变化时允许重新翻译，尤其避免过早固定日语译文。前后文仅作为输入数据。
- 同一条字幕的待处理最终修订合并为最新版本；不同语句仍保留顺序，不丢弃整句。旧请求不能覆盖较新结果。
- General 的本地翻译设置增加「延迟诊断」：分别记录识别、排队、翻译首段与整体时序的 p50/p95。最多保存 1000 条数字样本，不保存音频、原文、译文或密钥。
- 诊断窗口提供英、日到中文固定「文字增量回放」，与实际音频测试分开显示。

## 已验证

发布编译通过；应用打包后严格签名校验通过。客户端检查覆盖 SSE 首段/结束、截断、思考标签、取消、错误信息脱敏，以及增量复用、修正失效、上下文边界、日语原文无损切分、音频时间映射。独立命名验证构建中检查了配置和诊断弹窗，并实际调用本机 35B 完成两轮文字回放。

## 安装与实际采样

1. 停止并退出旧版，解压应用 ZIP，使用新应用替换之前的 Local Qwen 应用。不要同时运行多个副本。
2. General → Processing Mode 选择 Apple，翻译引擎选择本地模型；确认服务地址与模型 ID。生产应用标识保持不变，以沿用配置。
3. 先完成一次「测试翻译」让模型预热；选择要测试的实际源语言与目标语言。
4. 打开「延迟诊断」清空样本，播放同一段约 60 秒的视频并启动字幕，再停止采集、复制报告。英语和日语分别清空后采样；换模型、暂停或重新启动后也重新清空。
5. 将报告与主观观察一起提供，才能区分 Apple Speech 等待与模型首段等待，再决定是否替换识别引擎或翻译模型。

## 限制

音频帧末端→文字是识别范围末端的到达时间估算，不是人工标注的句尾延迟。流式中途变化可能改写尾部；分段翻译也可能损失跨句语义。此版本不能承诺会议产品级延迟或消除 Apple Speech 自身等待。

完整音频回放对照未完成：系统未生成有效测试音频，识别测试未取得可用语言；自动权限审批拒绝了测试音频生成所需系统服务访问。因此没有可报告的真实音频延迟结果，未因这一限制而申请额外录音权限。

本 ZIP 为本机 ad-hoc 签名的 arm64 应用，未进行 Apple 公证。当前环境不支持 DMG 创建设备访问，因此交付应用 ZIP。源码随包单独提供。
