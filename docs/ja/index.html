Apple Silicon · macOS 14 以降 · macOS 27 対応

Mac で使えるリアルタイム二言語字幕

外国語の動画、ポッドキャスト、会議を字幕で追えます。Mac の音声やマイク入力を文字起こしし、原文と訳文をフローティング表示したり、記録として保存したりできます。

フローティング字幕

原文、訳文、またはその両方を表示できます。動画を見ながら、字幕をプレーヤーの近くに配置できます。

端末内の音声認識

アプリ内で Nemotron または Qwen3-ASR をダウンロードできます。翻訳には同じ Mac 上の LM Studio、または翻訳対象のテキストだけを送信する Index オンライン翻訳を使えます。

文字起こしの保存と編集

原文と訳文をテキストファイルに保存し、文訳で読み返したり、編集したり、名前を変更したりできます。

Mac で使い始める

Apple Silicon（M1 以降）と macOS 14.0 以降が必要です。macOS 27 にも対応し、表示言語は日本語、英語、簡体字中国語から選べます。

詳しいインストールガイド ↗

  1. 文訳をインストールします。 DMG を開き、文訳を「アプリケーション」にドラッグします。
  2. 音声入力を選びます。 Mac の音声またはマイクを選び、必要な権限を許可します。システム音声のみの取り込みには macOS 14.2 以降が必要です。
  3. 音声認識と翻訳を設定します。 ローカルモードで音声認識モデルをダウンロードし、必要に応じて LM Studio または Index オンライン翻訳を設定します。
  4. 聞き取りを開始します。 原文と訳文の言語を選び、字幕に表示する内容を設定します。
