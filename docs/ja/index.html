YouTube 字幕の事前読み込み

Chrome／Safari の動画時間に字幕を同期します。端末内キャッシュは自動で読み込み、不足分のみ再開できます。任意の OpenAI 音声認識では音声を送信し、API 利用料が発生します。

フローティング字幕

原文、訳文、またはその両方を表示できます。動画を見ながら、字幕をプレーヤーの近くに配置できます。

端末内の音声認識

アプリ内で Nemotron または Qwen3-ASR をダウンロードできます。翻訳には同じ Mac 上の LM Studio、または翻訳対象のテキストだけを送信する Index オンライン翻訳を使えます。

文字起こしの保存と管理

原文と訳文をテキストファイルに保存し、内容のコピー、名前の変更、保存先のファイルの表示ができます。

Mac で使い始める

文訳 1.16.9（ビルド 1273）は Apple Silicon（M1 以降）と macOS 14.0 以降に対応します。macOS 27 にも対応し、表示言語は日本語、英語、簡体字中国語から選べます。

詳しいインストールガイド ↗

  1. 文訳をインストールします。 DMG を開き、文訳を「アプリケーション」にドラッグします。
  2. 音声入力を選びます。 Mac の音声、マイク、またはメディアモードで YouTube を選び、必要な権限を許可します。システム音声のみの取り込みには macOS 14.2 以降が必要です。
  3. 音声認識と翻訳を設定します。 ローカルモードで音声認識モデルをダウンロードし、必要に応じて LM Studio または Index オンライン翻訳を設定します。
  4. 聞き取りを開始します。 原文と訳文の言語を選び、字幕に表示する内容を設定します。

文訳（Wenyi）は himomohi が開発した AirTranslate をベースにしています。上流の Apache-2.0 ライセンスと著作者表記を引き継いでいます。
