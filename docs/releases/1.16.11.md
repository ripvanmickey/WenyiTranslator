# 文译 1.16.11（1281）

## 更新内容

- **媒体字幕 AI 校对。** 选择音轨识别后，勾选「加载后 AI 校对原文」。字幕准备完成后，文译用当前选定的翻译模型检查前后文中的同音误识别和术语错误。改动段落会重新翻译，原时间码保留，结果写入本机缓存。
- **复用旧字幕缓存。** 已经准备好的音轨字幕可直接点击「校对原文」。校对请求只发送字幕文字，可能产生额外 API 用量。停止后可以继续校对剩余段落。
- **缩短悬浮字幕。** 媒体字幕的长段落优先按句子或短语分两次随视频显示。
- **跳过空记录。** 停止、定时保存和退出时会检查字幕内容，只有原文或译文有实际文字时才保存。

## 安装

适用于 Apple Silicon Mac（M1 或更新芯片），系统要求为 macOS 14 或以上。退出正在运行的文译，打开 `Wenyi-1.16.11-1281-macOS14-arm64.dmg`，把「文译.app」拖入「Applications」。

安装包使用临时签名，尚未经 Apple 公证。
