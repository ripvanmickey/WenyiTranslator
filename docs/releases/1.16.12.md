# 文译 1.16.12（1283）

## 更新内容

- **媒体字幕默认本机识别。** 字幕来源默认选中「Nemotron 音轨识别 · 本地」，翻译模型默认选中「Index 在线翻译」。音轨在 Mac 上识别，Index 只接收待译字幕文字。首次识别前需下载 Nemotron 模型。
- **继续使用已有字幕。** 如果旧字幕用的是 YouTube 已有字幕或其他组合，选择原来的字幕来源、翻译模型和语言即可匹配缓存。媒体字幕也可在「已保存记录」中导出 SRT。
- **自定义悬浮窗宽度。** 在「设置 → 悬浮字幕 → 高级选项 → 窗口宽度」调整。实时和媒体悬浮窗共用并记住这个设置。
- **已保存记录详情顶部对齐。** TXT 和媒体字幕的详情卡片都与左侧列表顶部对齐。

## 安装

适用于 Apple Silicon Mac（M1 或更新芯片），系统要求为 macOS 14 或以上。退出正在运行的文译，打开 `Wenyi-1.16.12-1283-macOS14-arm64.dmg`，把「文译.app」拖入「Applications」。

安装包使用临时签名，尚未经 Apple 公证。如果你确认安装包来自本项目的 GitHub 发布页，可以在首次尝试打开后，从「系统设置 → 隐私与安全性」选择「仍要打开」。

## 验证

媒体回归覆盖默认选项、旧缓存载入和浏览器同步。悬浮窗宽度与记录布局使用演示数据核对。安装包已通过挂载、签名和最低系统版本检查。本构建尚未在 macOS 14 实机验证启动。
