# 可选纯音频采集（build 1167）

## 开关

设置 → Audio →「纯音频采集（实验）」。默认关闭并保留此前 ScreenCaptureKit 方式。停止字幕采集后才能更改；选择麦克风时开关禁用，但偏好保留。偏好跨启动保存。沿用 build 1166 的增量字幕、本地模型配置和延迟诊断。

开启后，在 Mac 音频模式下使用 Core Audio Process Tap 和私有聚合输入，仅采集系统声音，不创建 SCStream、不枚举屏幕、不请求屏幕录制权限、不注册画面输出。首次启动可能出现 macOS 系统音频录制权限提示，需要用户自行决定授权。失败时明确显示错误，不自动退回屏幕捕获。

不改变系统默认输出设备，不静音播放器，不安装驱动。仅在采集期间保留私有音频对象；停止时按 IOProc → 聚合输入 → Tap 的顺序释放。排除本应用音频，避免翻译语音回流。所有系统播放声音仍可能被采集，不是仅限 Netflix。

## 性能与兼容性

硬件音频逐块转换到识别引擎请求的单声道采样率；没有新增句子等待或音频批处理窗口。识别、流式翻译和模型配置保持原有流程。不能据此承诺更低的实际总延迟。

纯音频接口减少对屏幕捕获的依赖，但不会解除 DRM。Netflix 等受保护内容可能仍不允许采集或返回静音，本版不保证不黑屏、不保证可获取其音频。若没有声音，检查系统音频录制权限；切换输出设备后如未恢复，可停止后重启采集。

## 验证范围

- 完整发布编译与应用 ZIP 解压后的严格签名校验。
- 合成音频检查：44.1kHz / 48kHz、交错 / 非交错双声道 → 16kHz 单声道，验证样本时长、格式、数据就绪和回调内存复用后数据仍被正确持有。
- 验证未启动和重复停止的安全清理。
- 独立验证应用确认：默认关闭、可开启、切换麦克风后禁用、回到 Mac 音频后保留开启；退出后偏好文件中正确保存为开启。未启动实际录音。
- 合成音频测试不启动系统录音、不请求权限，不代表硬件链路、Netflix 播放或真实延迟已通过测试。

## 使用对照

退出旧版，解压并替换 Local Qwen 应用。先使用普通视频或本地音频验证新模式有声音，再自行检查实际播放器的画面和字幕表现。可在 General → 延迟诊断中清空后测量。打开与关闭开关时使用相同视频、语言和模型分别测量，避免混淆识别等待与采集差异。

交付为 macOS 26+、Apple Silicon 的应用 ZIP，build 1167，采用本机 ad-hoc 签名，未获 Apple 公证。源码单独提供。
