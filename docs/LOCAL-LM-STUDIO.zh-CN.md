# AirTranslate 1.16.0：LM Studio 本地翻译修改版

这是基于官方 v1.16.0（提交 6e0ab28935f4ce0860cfc23cd43d6e9904f3a438）的非官方修改版。本次提供已编译的 Apple Silicon 应用 ZIP：AirTranslate-1.16.0-Local-Qwen-fix3-arm64.app.zip。DMG 封装需要设备权限，当前自动审批策略拒绝了此权限，因此未在此环境生成 DMG。

## 已实现

在「设置 → 通用」新增「本地模型翻译 · LM Studio」：启用开关、服务地址、模型 ID、模型列表读取、可选本地密钥、日中翻译测试。配置自动保存，密钥单独保存在 macOS 钥匙串。

字幕流程为：系统音频 → Apple Speech 日语识别 → LM Studio 本地 Qwen 文本翻译 → 原有双语字幕。此功能不调用本地模型的音频识别接口。

启用开关会切换到 Apple 工作流，关闭 Jev，选择 Apple 系统语音并关闭译文朗读。切换到其他云端音频模式时，本地翻译配置保留，但不参与该模式。只转写模式不调用翻译。

## 安装

解压 `AirTranslate-1.16.0-Local-Qwen-fix3-arm64.app.zip`，把「AirTranslate Local Qwen.app」拖入「应用程序」，然后从应用程序文件夹启动。不需要重新编译。

如果需要 DMG，将 `制作DMG.command` 与应用 ZIP 放在同一文件夹，双击脚本即可在你的 Mac 上调用系统磁盘映像工具制作 DMG；也可在终端用 `bash` 执行该脚本。脚本不会重新编译或启动应用，不覆盖已有同名 DMG，也不修改系统安全设置。此脚本已完成语法检查，因当前设备权限限制未执行实际 DMG 创建验证。

修改版使用独立的应用名称和标识 `dev.appcaster.AirTranslate.LocalQwen`，可与原版并存。不要同时让两份应用采集同一段音频。修改版需要单独授予屏幕/系统音频录制、语音识别以及按需麦克风权限。

这是本机 ad-hoc 签名的构建，没有 Apple 公证。如果系统阻止首次启动，请通过系统设置中的「隐私与安全性」查看允许打开选项；不要全局关闭系统安全检查。

## 配置步骤

1. 在 LM Studio / Bionic 保持「本地模型 API」服务运行。
2. 打开 AirTranslate「设置 → 通用 → 本地模型翻译 · LM Studio」。
3. 开启「使用 Apple 语音识别 + 本地模型翻译」。
4. 服务地址填写 `http://localhost:1235/v1`，与你截图中的端口一致。
5. 如果本地服务启用了身份验证，填写其本地密钥并点「保存密钥」；未启用则不需要密钥。这里不使用 OpenAI 云端密钥。
6. 点击「读取模型列表」，从列表选择你的 Qwen。以服务器实际返回的模型 ID 为准，不需要猜测名称。
7. 点击「测试日中翻译」。测试只发送固定句子「今日はいい天気ですね。」。
8. 回到主窗口，选择日语为原文语言、简体中文为译文语言，再开始采集。首次使用 Apple Speech 仍可能需要下载系统语音资源并授予采集权限。

更换服务地址、模型或启用状态前停止采集；采集和启动期间配置会锁定。

## 本地边界与错误处理

只接受 `localhost`、`127.0.0.1`、`::1` 的 HTTP/HTTPS 地址，路径必须是 `/v1`。不接受远程主机或带用户名、密码、查询参数的 URL；不跟随重定向。该限制是为这次「同一台 Mac 上的本地模型」需求设计的，不支持局域网另一台机器。

客户端用 `GET /v1/models` 读取模型。fix2 对 Qwen 优先调用 LM Studio 原生 `POST /api/v1/chat`，明确设置 `reasoning: off`、`store: false`，不启用工具或插件，输出上限为 4096 token；只提取 message 译文，不显示 reasoning。参考官方接口：https://lmstudio.ai/docs/developer/rest/chat 。仅在原生接口明确返回 404/405 时，才改用同一本地服务的兼容接口，并传入关闭思考参数；其他错误不会静默回退。没有云端回退。

连续日语按最多 180 个字符分段，不依赖空格或句号。若输出仍被截断，最多再进行两层短段重试，不把不完整输出标记为完整译文。新增「测试长句翻译」按钮。请求超时仍为 90 秒，资源总超时 120 秒。

如果你之后主动选择其他云端采集引擎或云端朗读，其自身的云端数据路径仍然适用。本修改版不是对整个应用的网络隔离工具。LM Studio 自己的日志、模型行为及插件配置也由其自身管理。

## 构建

本修改版增加 Swift 6.3 工具链兼容：用旧工具链构建时，不编译 macOS 27 专属的音频适配器，继续使用原有 macOS 26 的 16 kHz 单声道音频路径；Swift 6.4+ 构建保留原有适配器。另修复两处旧编译器下的名称遮蔽问题。当前 Mac 为 Apple Silicon，运行系统 macOS 26.6.2，编译器 Swift 6.3.3，SDK macOS 26.5。

在源码根目录可执行：

```sh
bash script/build_local_dmg.sh
```

成功后安装包位于 `dist-local/`，脚本只构建、签名和打包，不启动应用。完整项目测试仍需安装包含 Swift Testing 的完整 Xcode。

## fix3（build 1163）：27B 加载 HTTP 400

从本机 LM Studio 日志确认：27B 自动加载曾报告 `MLX AutoFit selected a context length of 262144, below the required minimum of 4197934`。它是模型加载失败，不是地址或密钥错误。

fix3 对每次无历史字幕翻译请求明确设置 `context_length: 8192`，保留输出上限 4096、关闭思考和短段重试。同时在 HTTP 失败时显示服务返回的实际错误信息，并隐藏当前本地服务密钥。

已在独立临时验证副本中，以你的真实 `qwen/qwen3.8-27b` 完成长句翻译，得到中文回复，没有再返回 HTTP 400；没有开始音频录制。新增上下文参数与详细错误/密钥隐藏检查通过，正式构建成功，最终 ZIP 解压后的代码签名严格检查通过。

更新方法：停止并退出已安装的 AirTranslate Local Qwen，解压 fix3 ZIP，用其中同名应用替换「应用程序」里的旧版。保留地址 `http://localhost:1235/v1`，选择 `qwen/qwen3.8-27b`，先执行「测试长句翻译」。此版本 build 为 1163。
